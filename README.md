# WTD_habitat_selection
Repository for representative code replicating analysis in the manuscript, "White-tailed deer habitat use and implications for chronic wasting disease transmission."  

Where possible, I have included code as RMarkdown scripts with HTML outputs so users can see analyses in context. The data for this manuscript is not publicly available*, so the HTML files help document methods in light of this.

### What's inlcuded in this repository:

1. Intra- and inter-annual site fidelity analysis
2. Activity patterns: exploratory plotting and GAMM fitting; **Activity_patterns.Rmd**


### What's not included in this respository:

1. Fitting continuous time movement models (CTMM) and home range estimation. Code for this thoroughly documented in literature, and we point interested users to [Silva et al 2021, *Methods in Ecology and Evolution*](https://doi.org/10.1111/2041-210X.13786)

*At the time of publication, data were not available from the Wisconsin Department of Natural Resources; restrictions apply to the availability of these data, which were used under a data sharing agreement for the current study, and so are not publicly available. Data may be requested from the Wisconsin Department of Natural Resources through Daniel Storm (DanielJ.Storm@wisconsin.gov).
